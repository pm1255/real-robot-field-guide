# 采集任务书模板

本文件是空白模板。所有“待填写”都不是默认设备参数；完成配置与短轨迹检查后再正式采集。

## 任务与范围

- 任务 ID／任务书版本：待填写
- 任务描述及给模型的指令：待填写
- 实际部署范围：待填写固定／变化的物体、位置、朝向、场景与机器人起点
- 成功的可观察条件及结束后观察要求：待填写
- 失败、超时、中止及需要人工介入的条件：待填写
- 复位流程和每轮一致性检查：待填写
- 不属于本批数据覆盖范围的情况：待填写

## 硬件与版本

| 项目 | 本批配置／证据 |
|---|---|
| 机器人代号、具体型号、固件、SDK／驱动 | 待填写 |
| 夹爪、指尖结构、实际行程、安装版本 | 待填写 |
| 控制电脑系统、依赖环境、代码提交 | 待填写 |
| CAN 适配器、接口、厂商要求的配置 | 待填写 |
| 相机身份→输入键→安装视角 | 待填写 |
| 原始分辨率／FPS、裁剪／缩放、颜色和翻转 | 待填写 |
| 关节标定／相机内参／外参的用途、标识、哈希 | 待填写；不需要的项目写明原因 |
| 工位与装配照片、基准画面 | 待填写 |
| 遥操设备、映射与版本 | 待填写 |

公开版本可用设备代号，内部应保留与真实硬件的对应关系。

## 动作与时间契约

| 字段 | 必须明确的内容 |
|---|---|
| 实测状态 | 字段名、维度、关节顺序、单位、时间来源 |
| 下发命令 | 关节／末端，绝对／相对，单位、参考系、旋转约定 |
| 相对动作参考 | 实测状态／上一条命令／其他；重建方式 |
| 夹爪反馈和命令 | 开闭方向、比例或物理单位、行程映射 |
| 观测动作配对 | 观测时刻、动作生效／发送时刻、时钟转换和匹配规则 |
| 实际采样 | 目标频率、实测新帧率、间隔与最大缺口统计 |
| 输入失效与保持 | 未就绪、松手、超时、掉线、退出的明确行为 |
| 启动与复位 | 目标来自哪里、实际副作用、现场验证记录 |

## 录制事件

| 状态／事件 | 实际触发方式 | 文件与机器人行为 |
|---|---|---|
| 准备完成 | 待填写 | 待填写 |
| 开始录制 | 待填写键位／按钮／界面；含焦点要求 | 待填写 |
| 成功／失败／中止 | 待填写各事件 | 待填写各标签与边界 |
| 保存完成 | 待填写可确认的反馈 | 待填写刷盘与回读检查 |
| 复位 | 待填写 | 待填写 |
| 机器人停止 | 待填写对应设备和软件流程 | 不与停止录制混用 |

## 条件覆盖与分批计划

使用 [coverage-matrix.csv](coverage-matrix.csv)定义条件组合、权重与有效数量要求，再在 [collection-log.csv](collection-log.csv)逐条关联。

- 常见条件与关键边界：待填写
- 关键阶段和恢复状态：待填写
- 计划独立有效 episode 数及依据：待填写，不用总帧数替代
- 操作者／日期／物体实例变化安排：待填写
- 分批抽查、疲劳及复位耗时安排：待填写
- 训练／开发／最终测试的分组留出规则：待填写

## 质检与归档

- 短轨迹回读：图像／动作／状态／夹爪／时间／标签／尾部，待填写结果与证据。
- 有效标准：待填写，区分未检测、证据不足、已确认异常和检查通过。
- 数据缺口、损坏、标签争议的隔离方式：待填写。
- 失败与纠正轨迹用途：待填写；不要无标签混入常规专家 SFT。
- 数据清单、哈希、输出格式、存储与备份：待填写。
- 正式采集监控入口及实际数据显示检查：待填写；尚未启动写“等待”。
- 本批结论、覆盖缺口与后续补采：待填写。
