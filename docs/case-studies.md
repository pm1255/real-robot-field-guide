# 实战案例：公开复盘与现场材料整理

这三篇复盘展示了数据、装配、标定和执行方式如何共同影响真机表现。下面区分作者报告的经过与本仓库的机制分析；它们是公开案例，**没有作为我们自己工位已验证的事故发布**。

原文相关内容已阅读；没有独立复现实验，也不采用跨硬件成功率排名。核对明细见 [来源目录](../resources/sources.json)。

另新增 [CS-04 双臂 Piper 擦黑板](#cs-04)：它来自提供的月报摘录、受限源码／日志和示教关键帧，证据状态与三篇公开文章分别记录。

<a id="cs-01"></a>
## CS-01 Sherry Chen：相机、关节标定与覆盖同时影响 ACT

**来源与条件：** [A01 原文](../resources/articles-and-code.md#a01)，SO-101／ACT，2025-09-30。

### 作者报告了什么

采集与评测间相机位置变化，某视角夹爪指尖重叠、难以观察抓取细节；临时位置的关节校准文件丢失，后续不正确的重标定改变了偏置。作者还发现随机摆放的位置分布成团，有些区域缺少示范，示范本身也存在抓取位置不够准确的情况。

作者描述了固定装配、改善视角、规范校准和采集分布等调整，并展示成功、失败与干预。多项调整发生在迭代中。

### 原因怎样串起来

| 层次 | 机制解释 | 支持范围 |
|---|---|---|
| 观测 | 相机位置与遮挡变化，改变模型实际输入 | 作者报告变化；不证明所有视角偏移都会失败 |
| 动作语义 | 重标定改变偏置，相同角度不再对应原姿态 | 对应作者描述的校准经过；文件丢失本身与重新标定分开 |
| 示范分布 | 局部聚集留下未充分示范区域 | 作者对采集分布的回顾，不是任意随机采样都失效 |
| 示范质量 | 模型可能继续模仿不准确抓取 | 基于监督学习机制的解释，未隔离每项变化贡献 |

### 可以带走什么

装配和标定要跟数据版本走；检查最终输入及关键动作；采完后看实际条件分布。数据总量、loss 和程序启动成功，都不足以单独排除这些问题。

**结论边界：** 同型号相机身份难区分不是物理 USB 掉线的充分证据；各轮多变量变化，不能计算某项调整的独立收益。迁移到 Piper 时保留管理原则，具体校准按本型号流程。

对应：[CAM-01～05](camera-and-calibration.md)、[DATA-01～02](data-quality-and-coverage.md)、[AN-02～03](causes-and-lessons.md#an-02)。

<a id="cs-02"></a>
## CS-02 ggando：更多示范，仍可能抓空或跟随滞后

**来源与条件：** [A02 原文](../resources/articles-and-code.md#a02)，SO-101、腕部 RealSense D405 与外部 C920，SmolVLA 微调及 ACT 对比，2026-03-01。

### 作者报告了什么

作者描述早期在约 30 cm 范围录制 50 条示范，loss 很低而真机仍抓空；后续缩小范围、提高局部示范密度并规范抓取方式。一部分示范先推再抓，另一部分直接抓；更换夹爪与重标定也影响了旧模型。

采集链路还出现 USB 2.0 连接和相机 I/O 阻塞遥操循环的问题。后者让录制时的主从跟随滞后，直接影响示范过程。

### 原因怎样串起来

有限示范分散在更大范围，每类关键状态的有效经验可能不足；同类观测下混合不易区分的操作技巧，又增加学习难度。硬件和标定改变后，旧经验的物理对应关系需要复核。采集循环若阻塞，人做出的意图与机器人当时执行也可能不同步。

这里的“密度”“一致性”“装配”“时序”是四个问题。只增加条数，没有证据说明它会同时解决另外几项。

### 可以带走什么

先在明确范围内建立准确且稳定的基线，按关键条件扩展；记录动作来源与实际时间，检查录制是否降低操作质量。发现滞后时分环节计时，区分设备连接、取图和写盘。

**结论边界：** 上述数量是作者当时的配置，不是 Piper 采集建议。多轮同时改变多个变量，不能将最终改善单独归功于数据、相机或训练方法。

对应：[DATA-01～03](data-quality-and-coverage.md)、[IO-02～04](capture-and-storage.md#io-02)、[AN-04](causes-and-lessons.md#an-04)、[AN-08](causes-and-lessons.md#an-08)。

<a id="cs-03"></a>
## CS-03 ML6：低 loss、展示顺滑与真实闭环成功是不同证据

**来源与条件：** [A03 原文](../resources/articles-and-code.md#a03)，SO-100、ACT 与 GR00T-N1；2025-11-27 发布，2025-12-02 更新。

### 作者报告了什么

团队讨论抓放与毛巾操作中的精度、数据覆盖和恢复问题：模型离线拟合并不能直接证明精细操作成功。推理和网络耗时也会在动作段之间造成停顿。文章披露部分 GR00T 演示省略了推理暂停。

不同轮次数据量增加时，任务范围也可能变化，因此简单横向比较一列成功率会混入测试条件差异。

### 原因怎样串起来

离线 loss 衡量指定数据和目标下的误差；真机还涉及连续决策、接触状态和误差后的恢复。执行延迟让模型根据较旧观测动作，进一步改变闭环行为。视频剪掉等待不会修复执行，只会改变展示证据。

### 可以带走什么

将动作拟合、部署耗时、完整成功率、介入与失败阶段分开记录。比较数据或模型前固定任务范围及协议；展示视频明确剪辑，逐次原始记录保留等待与失败。

**结论边界：** 没有据文章得出 ACT 或 GR00T 的通用优劣排名，也没有把剪辑披露视为作者伪造结果。文章指出了问题，不代表本仓库验证了某个延迟修复方案。

对应：[RUN-01、03、04](training-and-deployment.md)、[EVAL-02～04](evaluation.md#eval-02)、[AN-01](causes-and-lessons.md#an-01)、[AN-10](causes-and-lessons.md#an-10)。

## 三篇公开案例共同留下的原则

先核对输入和动作的物理含义，再检查独立有效示范及关键阶段覆盖；部署与评测保留真实时序和完整尝试。每次调整尽量明确变化因素，结论只写证据支持的范围。

## CS-04 双臂 Piper 擦黑板：接口、运动控制与接触分层定位

**来源与条件：** F01 提供的月报摘录、F02 授权只读核对的源码／旧日志、F03 训练示教关键帧；核对日期 2026-10-29。原始材料不随本仓库分发，公开摘要见 [完整案例](blackboard-wiping.md)和 [证据摘要](../resources/blackboard-evidence.json)。

材料涉及过热掉臂、甩臂、慢求解、倾斜压持不足、死角超时，以及相机槽位和夹爪目标问题。重新统计的既有相机表标记 37/70 异常；代码支持连续夹爪目标与 EEF-rel 参考的说明。它们支持具体数据／接口判断，但不能替代现场故障验收。

可以带走的方法是：沿模型输出、动作恢复、IK、下发和实测反馈找第一个异常；先修执行可靠性与语义，再查接触和覆盖。二值目标丢失的连续意图不能凭逆映射恢复；相机跨 episode 映射不同也不证明单条录像中途变化。

**结论边界：** 月报的 5/10、泛化成功与 DLS 修复未独立复验；另见的关节服务计时不是该版 IK 性能，训练示教也不是已核实的自主成功录像。当前公开 RoboDojo 真机列表没有擦黑板；接口名称不能证明官方收录。

对应：[WIPE-01～08](blackboard-wiping.md)、[SOP 与流程](blackboard-wiping.md#wipe-workflow)、[证据规则](evidence-levels.md)。
