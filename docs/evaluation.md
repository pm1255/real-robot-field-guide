# 真机测评

可靠结论来自预先约定的成功标准、可比较的条件和完整逐次记录。训练 loss、数据回放、一次成功视频和多次自主闭环测评分别证明不同事情。

<a id="eval-01"></a>
## EVAL-01 成功定义不明确

- **现象与影响：** 物体短暂到位就标成功，随后滑落；不同操作者对“完成”理解不一致。
- **先查：** 是否规定了最终可观察状态、允许动作、时限、释放后保持／观察要求和失败判据。
- **处理：** 测试前填写 [测评协议](../templates/evaluation-protocol.md)，明确人工确认或自动判定方法，并保留依据。保持时间按任务定义，不直接套用他人的数值。
- **验证：** 复核末段画面与结果标签；标注依据不足时记“待核查”，不能自动判成功。
- **依据与范围：** [E01 公开逐次评测](../resources/videos.md#e01)、[E02 协议](../resources/articles-and-code.md#e02)是记录形式参考，本仓库未独立审计其所有结果。

<a id="eval-02"></a>
## EVAL-02 模型之间条件不一致

- **现象与影响：** 模型 A 测固定物体，模型 B 测新物体；硬件、相机或时限也发生变化，百分比无法直接比较。
- **先查：** 起始姿态、摆放清单、物体实例、光照／背景、标定、夹爪、检查点、执行频率、时限与介入规则。
- **处理：** 固定计划条件与预算，必要时随机或平衡测试顺序，记录温度、磨损等可见漂移。分布内与未见条件分开统计。
- **验证：** 将两组逐次记录按条件对应；确实无法控制的变化在结论中说明，避免单因素归因。
- **依据与范围：** [A01](../resources/articles-and-code.md#a01)、[A03](../resources/articles-and-code.md#a03)；[E01](../resources/videos.md#e01)相机配置间检查点步数不同，不能据其结果隔离相机数量的因果作用。

<a id="eval-03"></a>
## EVAL-03 分母、重试、介入与不确定性不清楚

- **现象与影响：** 只报“成功率 80%”，不说明试了几次、是否重摆或有人接管；小样本结果易被过度解读。
- **先查：** 所有尝试、成功、失败、超时、中止、硬件异常、重试和人工介入是否有独立记录。
- **处理：** 报告成功次数／协议规定的有效次数，同时补报全部尝试数及排除理由；自主成功和介入后完成分开。异常如何计入需预先定义，不能看结果再挑分母。
- **验证：** 每条结果能对应视频与日志，汇总可由逐次表重算。按适合试验设计的方法给出不确定性；二项置信区间的常用解释依赖试验独立性等假设。
- **依据与范围：** [E01](../resources/videos.md#e01)提供逐次记录范例；统计与介入规则为工程建议，没有通用的固定测试次数。

<a id="eval-04"></a>
## EVAL-04 回放与自主闭环测评混淆

- **现象与影响：** 预录动作在固定摆放中能执行，被当作模型能够自主识别并纠偏的证据。
- **先查：** 动作来自录制轨迹还是实时策略；是否使用实时相机反馈；是否有人接管或反复挑选成功尝试。
- **处理：** 分开记录离线文件回读、真机动作回放、遥操成功和自主闭环试验。回放有助排查接口，不能替代新条件下的策略评测。
- **验证：** 在明确记录动作来源的独立条件上测试；视频保留失败、等待与介入说明，剪辑演示另作展示材料。
- **依据与范围：** [V05 长课目录](../resources/videos.md#v05)分别列出评测与回放；[A03](../resources/articles-and-code.md#a03)披露演示剪辑限制。目录存在不等于逐段内容已完整核实。

<a id="eval-05"></a>
## EVAL-05 benchmark 缺少闭环证据

- **现象与影响：** 只有任务名或训练结束截图，却宣称已完成“采集→训练→评测”。
- **先查：** 是否有数据版本与质检、训练配置与检查点、部署版本、协议、逐次结果和汇总结论。
- **处理：** 用 [benchmark 台账](../templates/benchmark-register.csv)逐阶段记录状态及证据。启动、完成训练和完成真机验收是不同状态；同一任务多个检查点不自动算多个 benchmark。
- **验证：** 以预先约定的闭环完成标准计数，抽查每行能否找到对应产物。只保留占位或等待的任务不计入完成。
- **依据与范围：** 项目管理与证据归档建议；本仓库的模板没有真实 benchmark 结果。

## 推荐的最小证据链

任务定义／协议 → 数据清单与质量记录 → 训练配置／日志／检查点 → 部署与现场版本 → 每次试验视频和结果 → 分条件汇总及限制。

公开案例见 [150 次 SO-101 评测记录](../resources/videos.md#e01)。它包含成功与失败，比只看展示片更适合学习记录方式；不代表 Piper 的性能基线。
