# 常用词

| 词 | 本仓库中的意思 |
|---|---|
| 真机 | 真实机器人及其传感器，与仿真区分 |
| 遥操 | 人通过输入设备持续提供控制意图 |
| 录制器 | 将观测、状态、动作、时间和结果写为轨迹的组件；不等同于控制器 |
| episode／轨迹 | 一次有明确开始、结束和结果的任务尝试 |
| 示范 | 希望模型学习的行为记录；常规专家 SFT 需要期望动作 |
| benchmark | 有任务定义、条件、指标和评测协议的测试单元；具体计数由项目预先约定 |
| 后训练 | 在已有模型基础上继续学习的统称，可含示范微调或 RL；不专指在线强化学习 |
| SFT／模仿学习 | 利用示范观测和动作学习策略 |
| 在线 RL | 通过真实交互及奖励继续优化，额外需要奖励、介入与复位等机制 |
| EEF／TCP | 末端执行器／工具中心点；具体坐标定义取决于接口 |
| 绝对／相对动作 | 目标本身／相对指定参考的变化；必须写清参考点与组合方式 |
| 逆运动学 | 从目标末端位姿求满足约束的关节配置 |
| 逆动力学 | 从运动需求及动力学模型求力或力矩等，不等同于一般输入适配 |
| SpaceMouse | 可表达三维平移与旋转意图的输入设备，区别于普通二维鼠标 |
| CAN／USB-to-CAN | 常见控制总线／将电脑 USB 接口连接到 CAN 的适配设备 |
| 关节校准 | 编码器读数与关节角映射等，具体内容因设备不同 |
| 相机内参 | 焦距、主点、畸变等成像参数 |
| 外参／手眼标定 | 相机与其他坐标系的空间关系；手眼通常涉及相机与末端／机器人关系 |
| action chunk | 一次预测的一段未来动作，预测步数和实际执行步数可能不同 |
| 归一化 | 将原始数值转换到训练使用的尺度；部署需对应逆变换 |
| mask／padding | 标记有效元素／补齐长度或维度的占位值 |
| loss | 特定训练目标下的误差，不直接等于任务成功率 |
| 回放 | 使用已记录动作或数据再次执行／查看；不自动代表自主闭环控制 |
| 自主闭环 | 策略基于实际新反馈持续决策，人工介入需要另行标记 |
| 覆盖度 | 相对预先定义部署条件及组合的覆盖，不能只用帧数代表 |
| Phoenix | 同名可能对应不同项目或产品；A04 中指 AMD 电脑平台，不能仅凭名字认定是某模型 |
