# 证据等级与结论边界

把来源作者的观察、整理者的建议和本地实测分开。引用到原文不等于独立复现实验，视频标题写“全流程”也不能证明包含完整逐次验收。

## 核对深度

| 目录中使用的等级 | 表示什么 | 不能据此声称什么 |
|---|---|---|
| `original_text_read` | 已阅读原文相关章节或完整可见帖子 | 独立复现、因果关系已被证明 |
| `video_metadata_checked` | 已核对页面标题、作者、日期或时长 | 已完整观看、逐段代码已验证 |
| `chapters_cross_checked` | 公开章节目录经第二出处交叉核对 | 所有章节内容已观看或视频未经剪辑 |
| `dataset_card_and_viewer_checked` | 已看数据卡与预览规模 | 每条视频已审看、标签已独立审计 |
| `repository_metadata_checked` | 仓库存在与简介／默认分支已核对 | 代码可运行、与当前环境兼容 |
| `default_readme_checked` | 默认分支 README 已查看 | 目标硬件分支或演示提交已找到 |
| `public_source_snapshot_checked` | 固定版本源文件已核对，清单记录哈希 | 真机可用性或其他版本支持范围 |
| `linked_reference_only` | 原资料链接到该参考，未深入阅读 | 参考全文内容已核实 |

结构化明细见 [sources.json](../resources/sources.json)；代码文件清单见 [RLinf 源码清单](../resources/rlinf-source-manifest.json)。核对日期不是资料发布日期，也不是“当前兼容”的保证。

## 问题状态

- **公开案例：** 原作者在其硬件与版本上报告的经历，需要保留适用范围。
- **工程建议：** 根据接口、时序或实验设计提出的排查和验证方法，不作为已发生的故障。
- **现场已观测：** 有本工位可追溯的日志／画面，原因仍可能待核查。
- **原因待核查：** 现象支持某假设但证据不足，不写成确定根因。
- **现场已验证：** 记录验证方法、前后配置和证据，结论仍限定于验证条件。

## 当前整理的限制

主要经验来自 SO-100／SO-101／Koch 上的示范学习和监督微调。它们不是 Piper／π0.5／RLinf 在线 RL 的完整运行教程。

视频核对大多停留在页面与公开章节；部分页面有登录／试看限制。150 次公开试验只核对了数据卡和预览行数，未逐个审片；多相机配置只发布单个视角，且配置间检查点训练步数不同。

个人复盘中往往同时改变多个变量，不能将百分比差异归因于单一因素或推导通用采集条数。本仓库没有连接机械臂，也没有实际采集、训练或测评结果。
