# 遥操与动作接口

操作者发出控制意图，适配层把它变成机械臂支持的命令，录制器另行记录观测与动作。这三段都要接通。按键和动作含义由具体代码与配置决定，没有跨项目通用的“开始键”。

<a id="tel-01"></a>
## TEL-01 能遥操，不代表能录制

- **现象与影响：** 手柄能控制真实 Piper，但输出目录没有有效轨迹，或只有视频、没有对齐动作。
- **先查：** 输入设备→动作适配→机器人控制，以及相机／实测状态／下发命令→录制器，两条链路分别在哪里实现。
- **处理：** 明确每个字段的来源和保存位置；同时保留实测状态与下发命令，不能把二者混作同一个动作标签。
- **验证：** 先录几条短轨迹，退出后重新读取文件，核对画面、关节、夹爪、动作和结果。3～5 条可作为联调批次，不是训练量承诺。
- **依据与范围：** [D02 Piper 手柄教程](../resources/articles-and-code.md#d02)是控制教程；[C03 RLinf](../resources/articles-and-code.md#c03)提供通用录制框架。两者存在不等于已经集成。

<a id="tel-02"></a>
## TEL-02 末端输入与关节动作不匹配

- **现象与影响：** SpaceMouse 输出三维平移／旋转增量，而环境接受绝对关节角；直接拼接数字会改变控制含义。
- **先查：** 输入是绝对值还是增量、表示关节还是末端、处于哪个坐标系、环境真正接受什么目标。
- **处理：** 若环境只支持关节目标，末端方案通常需要目标位姿更新、逆运动学和约束处理；兼容主臂则需要关节布局与零位映射。逆动力学用于从运动需求求力／力矩，不是这里“鼠标转目标”的同义词。
- **验证：** 先检查纯计算的映射、单位和不可达目标处理，再按设备流程验证真机。普通二维鼠标需要轴或模式选择，不会自动产生完整六自由度意图。
- **依据与范围：** [C03](../resources/articles-and-code.md#c03)固定版本 Piper 使用关节目标；具体 SDK 的其他能力不代表环境已经支持。

<a id="tel-03"></a>
## TEL-03 单位、关节顺序与夹爪映射错误

- **现象与影响：** 动作幅度成倍变化、某个关节方向反了，或模型输出“开”却实际闭合。
- **先查：** 度／弧度、米／毫米、关节顺序、左右臂顺序、四元数顺序、基座／工具坐标系、夹爪比例与行程。
- **处理：** 为每个字段建立动作契约，写明训练值、反归一化后的值和最终硬件命令；不直接照搬其他机械臂配置。
- **验证：** 用已知样本检查变换往返，再对照实测反馈。目标和反馈允许有跟随误差，但字段语义必须一致。
- **依据与范围：** [C03](../resources/articles-and-code.md#c03)固定版本带夹爪 Piper 动作为 6 个弧度关节目标＋1 个开度比例；其他版本／硬件需另核对。

<a id="tel-04"></a>
## TEL-04 开始、成功、中止按键不明确

- **现象与影响：** 把准备动作录入数据、提前标成功，或把停止写盘误认为停止机械臂。
- **先查：** 实际启动入口、录制模式、键盘监听代码、焦点要求、按键提示和事件日志；键盘、手柄按钮都可能被配置为触发来源。
- **处理：** 在工位明确列出准备、录制、成功／失败／中止、保存、复位的状态与触发方式。录制结束、结果标记与机械臂停止分别定义。
- **验证：** 检查开始与结束事件是否对应文件边界、结果是否对应真实完成、保存结束后是否可读。
- **依据与范围：** [D02](../resources/articles-and-code.md#d02)的 START 是模式切换、A 是位置保存，不是通用录制键；[C03](../resources/articles-and-code.md#c03)的 episode 包装有自己的按键逻辑，需按具体模式核对。

<a id="tel-05"></a>
## TEL-05 初始化、复位与保持行为未验证

- **现象与影响：** 程序一启动就移动，松开输入后回零，或退出后仍使能保持。绝对关节动作中的零向量通常不是“没有动作”。
- **先查：** connect／reset／step／disconnect 的实际副作用；输入未就绪、超时、丢连接时发送什么，启动目标是否来自实测状态。
- **处理：** 先把初始姿态、输入有效性、保持、复位与停止行为明确写入适配要求，并按型号文档实施。软件退出不等于硬件急停。
- **验证：** 先审查代码及配置默认值，再在现场受控条件下核对各状态转换，不以参数名如 read-only 推断无副作用。
- **依据与范围：** [C03](../resources/articles-and-code.md#c03)固定版本 Piper 环境初始化有复位行为；这些是版本事实，不能直接推断任何未检查版本或设备的行为。

完整接线和新手解释见 [Piper 入门](piper-start.md)，采集状态顺序见 [工作流程](workflow.md)。
